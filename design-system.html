english4Me Design System

Every colour, size and component below is read live from css/style.css — the app's single source of truth. Change a token there and this page changes with it, so the reference can never drift from what ships.

01 Colour

Semantic tokens drive the whole UI. Signal Orange is action/primary, Clear Cyan is progress/accent, on Ink + Paper neutrals. Hex values shown are read from the current theme.

02 Colour roles & contrast

The key text/background pairings with their measured WCAG contrast ratio. AA needs ≥ 4.5:1 for body text (≥ 3:1 for large/bold ≥ 24px). This is why primary buttons use Ink text on Signal Orange and orange text on light uses Orange Deep — computed below, not asserted.

03 Typography

Plus Jakarta Sans for display / wordmark / buttons · Inter for body & UI · JetBrains Mono for small mono labels. The scale is the --fs-* tokens, rendered at their real sizes.

04 Spacing & radius

An 8px spacing system (--sp-*) and the corner radii (--r-*): cards 24, buttons 18, inputs/panels 16.

05 Elevation

Three very subtle shadow tokens (--shadow-sm/md/lg); on dark they deepen to stay visible.
